# Аэродинамическая характеристика вентилятора ВЦ-25М

Интерактивное веб-приложение для визуализации аэродинамической характеристики центробежного вентилятора ВЦ-25М.

![Аэродинамическая характеристика](https://img.shields.io/badge/Вентилятор-ВЦ--25М-blue)
![React](https://img.shields.io/badge/React-18.2-61dafb)
![TypeScript](https://img.shields.io/badge/TypeScript-5.7-3178c6)
![Vite](https://img.shields.io/badge/Vite-6.4-646cff)

## 📊 Описание

Приложение отображает аэродинамическую характеристику вентилятора ВЦ-25М с возможностью интерактивного взаимодействия:

- **Кривая полного давления (P)** — зависимость полного давления от расхода
- **Кривая статического давления (Pst)** — зависимость статического давления от расхода
- **Кривая мощности (N)** — потребляемая мощность на валу
- **Кривая КПД (η)** — коэффициент полезного действия

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: **http://localhost:5173**

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## 📁 Структура проекта

```
├── index.html                    # Точка входа HTML

│   └── data/

└── dist/                         # Собранные файлы (после build)
```
